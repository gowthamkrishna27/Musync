# Repository Setup Guide

## Prerequisites

To work on Musync locally, ensure you have the following prerequisites installed on your system:

### 1. General & System
* **Git**: Installed and configured.
* **Java Development Kit (JDK)**: JDK 21 (Eclipse Temurin, OpenJDK 21, or Android Studio JBR).
* **Node.js**: Node.js 20.x or higher (LTS recommended).
* **Python**: Python 3.10+ (with `pip`).
* **FFmpeg**: Required for audio stream transcoding in development/production environments.

### 2. Android Development
* **Android Studio**: Ladybug / Koala / Hedgehog with Android SDK Platform 35.
* **Android SDK Build-Tools**: `35.0.0`.
* **Android Emulator or Physical Device**: Android 8.0+ (API 26+).

---

## Quickstart Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/gowthamkrishna27/Musync.git
cd Musync
```

### Step 2: Install Backend Dependencies

```bash
cd backend
npm install
pip install -r requirements.txt
```

### Step 3: Configure Android SDK Path

Create `android/local.properties` (if not already generated by Android Studio) and set the path to your Android SDK:

```properties
sdk.dir=C\:\\Users\\<username>\\AppData\\Local\\Android\\Sdk
```

### Step 4: Verify Environment

Run backend diagnostics:

```bash
npm run dev
```

Visit `http://localhost:5000/debug/env` in your browser to confirm that Node.js, Python, `yt-dlp`, and `ffmpeg` are recognized.
